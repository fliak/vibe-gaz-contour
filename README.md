# ГазКонтур

Демонстрационная PWA для просмотра телеметрии и документов ШРП/ГРП. Три раздела: **Голос**, **Телеметрия**, **Документы**. Схемы открываются в просмотрщике из документов, телеметрии или команды помощника. Название, объекты и показатели вымышленные.

## Запуск и сборка

Нужен Node.js 20.19+ либо 22.12+.

```sh
npm ci
npm run dev
npm run validate-config
npm test
npm run build
npm run preview
```

Production-файлы находятся в `dist/`. Это единственный каталог, который nginx должен отдавать как приложение. Backend и постоянно работающий Node/Docker не нужны.

## Данные

- `public/config/app.json`: название, подпись и демо-команды.
- `public/config/objects.json`: каталог объектов, адреса, псевдонимы и пути к конфигурации.
- `public/config/objects/*.json`: метрики, статусы, оборудование, документы.
- `public/documents/<object-id>/`: файлы документов.

Чтобы добавить объект, скопируйте `public/config/objects/grp-2.json`, задайте новый стабильный `id`, затем добавьте запись в каталог `objects.json`. `id` в записи и файле должны совпадать. Добавьте его документы в `public/documents/` и укажите URL от корня сайта. После изменений выполните `npm run validate-config` и `npm run build`.

Метрики берутся из массива `metrics`: можно менять название, значение, единицу и диапазон, добавлять или удалять карточки. Иконки: `gauge`, `filter`, `thermometer`; неизвестная иконка заменяется манометром. Поле `aliases` помогает текстовому и голосовому поиску. Статусы: `normal`, `warning`, `deviation`, `alarm`, `unknown`. Если статус объекта не задан, используется наиболее серьёзный статус его метрик. Диапазон информационный: статус по нему автоматически не вычисляется.

Категории документов: `scheme`, `regime-card`, `passport`, `act`, `instruction`, `other`. Для основной схемы и основной режимной карты задайте `isPrimary: true`; допускается по одному основному документу каждой из этих двух категорий на объект. Идентификаторы документов уникальны во всём каталоге. Форматы JPG, PNG, WebP и PDF открываются в приложении; для остальных доступно скачивание. Файлы публичные.

Кнопка «Обновить» заново запрашивает JSON. Для изменения опубликованных данных без пересборки можно обновить соответствующие файлы в `dist/config/`; сохраните те же изменения в `public/config/`, иначе следующая сборка их перезапишет. Документы размещаются аналогично в `dist/documents/` и `public/documents/`. Изменение названия приложения подхватывается при повторном открытии.

## Команды

- «Какое давление на входе ГРП-2?»
- «Какое давление на выходе этого объекта?»
- «Покажи температуру в помещении»
- «Какая ситуация по ГРП-2?»
- «Покажи схему этого объекта»
- «Открой режимную карту ГРП-2»
- «Открой документы по этому объекту»
- «Обнови данные»

Обработчик работает локально, без LLM: ключевые слова, названия, псевдонимы. При неоднозначности предлагает варианты. Явное имя объекта меняет текущий объект; команды без имени используют текущий выбор. Последний объект сохраняется в `localStorage`.

Голос использует браузерный SpeechRecognition с `ru-RU` и запрашивает микрофон только по нажатию. При отсутствии API доступны текст и демо-команды. Озвучивание включается при наличии русского голоса speechSynthesis. Реальный микрофон и сервис распознавания нужно проверить в Chrome на Android: эмуляция браузера не заменяет эту проверку.

## PWA и офлайн

Service Worker генерируется при сборке, версия кэша зависит от сборки. Программная оболочка сохраняется при установке worker; конфигурация сохраняется только после успешной проверки структуры, начиная с первого открытия. Открытые документы до 15 МБ сохраняются отдельно (до 30 файлов). Браузер может удалить кэш при нехватке места. При отсутствии сети видна соответствующая отметка; голосовое распознавание офлайн не гарантируется.

Откройте HTTPS-сайт на Android, дождитесь загрузки, выберите в меню Chrome «Добавить на главный экран» / «Установить приложение». Если браузер предоставляет событие установки, в шапке появится кнопка «Установить».

## Nginx

В текущем проекте `medvedzol.soil.by.conf` уже подключает `deploy/app-locations.conf`; перед применением требуется системная проверка и reload, указанные ниже. Let’s Encrypt настраивает владелец сервера. Готовый пример: `deploy/medvedzol.soil.by.conf`. При уже работающем Certbot сохраните существующие SSL-директивы и перенесите настройки из `deploy/app-locations.conf` внутрь HTTPS-сервера, удалив дублирующиеся `root`, `index` и `location`.

Корень HTTPS-сайта: `/var/www/medvedzol/dist`. Каталог ACME challenge может остаться `/var/www/medvedzol`. Проверьте, что `/etc/nginx/mime.types` подключён; manifest должен отдаваться как `application/manifest+json`, JSON как `application/json`, PDF как `application/pdf`. Для старого mime.types при необходимости добавьте тип manifest в глобальную таблицу MIME.

```sh
sudo nginx -t
sudo systemctl reload nginx
```

Перед перезагрузкой `nginx -t` должен завершиться успешно. Не отдавайте исходный корень проекта: `index.html` там предназначен для Vite, а не для production.

## Проверки

`npm test` проверяет команды, неоднозначность, контекст, статусы и валидацию. Браузерные сценарии проверяют desktop и Pixel 7: навигацию, документы, запоминание объекта, ошибки JSON и файлов, обновление данных, офлайн-перезапуск.

```sh
npx playwright install --with-deps chromium
npm run build
npm run test:e2e
```

Снимки интерфейса и трассировки ошибок находятся в `test-results/`. Для повторного создания **исходных** демоданных и документов: `node scripts/demo.mjs` (перезаписывает демоконфигурации).

Технические справочники: [Vite](https://vite.dev/guide/), [Service Worker](https://developer.mozilla.org/en-US/docs/Web/API/Service_Worker_API/Using_Service_Workers).

## PDF на Android

На Android PDF открывается по исходному URL в той же вкладке: штатный просмотр Chrome работает отдельной страницей. При отсутствии `navigator.pdfViewerEnabled` на других устройствах используется такой же переход. Кнопка браузера «Назад» возвращает к выбранному разделу, объекту и фильтрам документов. На компьютере встроенный просмотр сохраняется; при ошибке доступен переход на прямой URL. Кнопка «Открыть отдельно» для PDF также использует текущую вкладку, без blob-ссылки.

Поддержку PDF отдельной страницей проверили на реальном Android. Автотесты проверяют прямой URL и возврат, подменяя только страницу нативного просмотрщика: интерфейс Android PDF не эмулируется.
