## Оставшиеся действия на сервере и устройстве

Владелец самостоятельно настраивает Let’s Encrypt. Выполнить с системными правами:

```sh
sudo nginx -t && sudo systemctl reload nginx
```

Полная системная проверка не выполнена агентом: `sudo -n nginx -t` требует пароль. Сервис nginx агентом не перезагружался. После reload открыть `https://medvedzol.soil.by` и проверить установку PWA и реальное голосовое распознавание на Android/Chrome. Браузерная эмуляция не подтверждает работу аппаратного микрофона и внешнего сервиса распознавания.

## Особенности тестового окружения

У сервера нет системных библиотек Chromium; для тестов пакеты Ubuntu распакованы в `/tmp/gazkontur-browser-libs/root`, без установки в систему. Здесь тесты запускались так:

```sh
LD_LIBRARY_PATH=/tmp/gazkontur-browser-libs/root/usr/lib/x86_64-linux-gnu npm run test:e2e
```

На обычной машине достаточно установить зависимости командой из README. Копия nginx-конфига до подключения приложения: `/tmp/gazkontur-nginx-before-app.conf`.

Исходные ТЗ, референс и пользовательский `task.html` не изменялись. Все изменения пока без git-коммита.
